# Code of Conduct

ThreadHaven follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, assume good intent and keep discussions about the work. Report unacceptable behavior privately to the maintainer through a [security advisory](https://github.com/LukaszFilipowski/ThreadHaven/security/advisories/new) or by email listed on the maintainer's GitHub profile. Reports are handled confidentially.
